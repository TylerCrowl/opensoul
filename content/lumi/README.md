# Lumi short scripts (demo)

Short 9:16 scripts for the demo character Lumi (see `assets/lumi/character.json`): a 1,000-year-old elf barista,
calm and deadpan, particular about coffee and a fan of real whole milk. Each file has the sections the app reads
(`opensoul/script_parse.py`): **Spoken script**, **Useful tip** and **Shot list**. Written for the project; Apache-2.0
with the repo.
