Public internet address

Where do I find this address?

1. Let other computers connect to the studio. ComfyUI answers only on its own computer until you start it with --listen. On the studio, start ComfyUI with its home-network address, for example python main.py --listen <studio address> --port 8188. Use this only on a network that you trust. Never use it on public Wi-Fi.

2. Find the studio's address.

  • DGX Spark or another Linux computer: open a Terminal on it. Type hostname -I. Use the first number. It often starts with 192.168. or 10. Its name plus .local often works too.
  • Mac: open System Settings, then Wi-Fi (or Network). Click Details next to your network. It shows the IP address. The name in General, then Sharing, then Local hostname, also works.
  • Windows PC: open Settings, then Network & internet, then Properties. Find the IPv4 address.

3. Type the address here. Put http:// in front and :8188 at the end. Then click Test connection.

The API helper (comfy-api-proxy) must also accept connections, on port 8189. Its --help shows how.

Is this safe?

Only your studio. OpenSoul talks directly to the address that you type here, over your own network. Nothing goes through other computers.

No account, no cloud, no tracking. There is no OpenSoul account, cloud server or telemetry. Your prompts, pictures and videos go only between this computer and your studio.

What OpenSoul sends. OpenSoul sends your generation jobs (prompts and reference pictures) to ComfyUI on your studio. The finished pictures, videos and voices come back.

One caveat. By default, ComfyUI has no password, so anyone on the same network can use it. Connect only on a network that you trust, like your home network. Never type a public internet address. Away from home? Use a private connection such as a VPN.

Open source. You can read every line. The connection code is in opensoul/launcher.py. Read how connecting works.
